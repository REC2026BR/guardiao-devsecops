# Politica de seguranca

## Reportar uma vulnerabilidade

Nao publique credenciais, dados pessoais ou detalhes exploraveis em issues
publicas. Use o recurso privado de advisories do GitHub ou envie o relato ao
responsavel de seguranca da organizacao.

Inclua:

- repositorio e commit afetado;
- impacto observado;
- passos seguros para reproduzir;
- evidencias sem dados sensiveis;
- sugestao de correcao, se houver.

Nao teste sistemas de terceiros nem producao sem autorizacao expressa.
